# CHOI DEPT

Single-page B2B portfolio for CHOI DEPT — AI Creative & Research Operations.

## Local preview

```bash
npm run build
npm run dev
```

Open `http://127.0.0.1:4173/`.

## Current hosting state

- GitHub: `https://github.com/cuj0218/choidept`
- Cloudflare Pages project: `choidept`
- Preview: `https://choidept.pages.dev/`
- Custom domains: added, DNS verification pending

The custom domain must be activated at the registrar before launch. For the preferred canonical setup, manage `choidept.com` in Cloudflare DNS, point the registrar nameservers to Cloudflare, and add a 301 redirect from `www.choidept.com/*` to `https://choidept.com/$1`.

## Before launch

- Replace representative work copy with verified case-study material.
- Connect the approved B2B contact endpoint.
- Review privacy and inquiry-collection copy.
- Confirm the final canonical domain and redirect rule.
